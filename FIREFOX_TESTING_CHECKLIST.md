# Firefox Testing Checklist

## 📋 Pre-Release Testing

### Загрузка и установка

- [ ] Расширение загружается без ошибок в `about:debugging`
- [ ] В консоли браузера нет ошибок JavaScript
- [ ] В консоли нет предупреждений безопасности
- [ ] Popup открывается при клике на иконку
- [ ] Все иконки отображаются корректно

### Основной функционал

#### YouTube Блокирование
- [ ] Страница YouTube открывается нормально
- [ ] Модальное окно приветствия появляется
- [ ] Кнопка \"Закрыть\" отображается и работает
- [ ] Отслеживание времени работает
- [ ] Счетчик времени обновляется каждые 10 секунд

#### Система уведомлений
- [ ] Уведомления системы появляются при превышении лимита
- [ ] Модальные окна отображаются правильно
- [ ] Toast уведомления видны
- [ ] Звук уведомления проигрывается (если включен)

#### Сохранение данных
- [ ] Настройки сохраняются при клике \"Сохранить\"
- [ ] Визуальная обратная связь (✅ Сохранено!) появляется
- [ ] После перезагрузки браузера данные остаются
- [ ] Синхронизация работает между вкладками

### Система очков и наград

- [ ] Очки чести отображаются в popup
- [ ] Звание обновляется при изменении очков
- [ ] Система наград срабатывает на YouTube
- [ ] Отложенные награды показываются корректно
- [ ] Счетчик дней без YouTube отслеживается

### Панель управления (Popup)

- [ ] Статистика загружается при открытии popup
- [ ] Время сегодня отображается правильно
- [ ] Дни без YouTube обновляются
- [ ] Очки чести показывают правильное значение
- [ ] Звание соответствует количеству очков

#### Настройки
- [ ] Лимит времени сохраняется
- [ ] Интервал напоминаний сохраняется
- [ ] Checkbox \"Блокировка включена\" работает
- [ ] Checkbox \"Только рабочее время\" работает
- [ ] Текущие настройки загружаются при открытии

#### Действия
- [ ] Кнопка \"Сбросить статистику\" работает
- [ ] Подтверждение перед сбросом появляется
- [ ] После сброса все значения обнулены
- [ ] Кнопка \"Режим железной воли\" блокирует YouTube

### Режим паники (Iron Will Mode)

- [ ] Активация режима панического блокирования работает
- [ ] Подтверждение диалога появляется
- [ ] YouTube полностью блокируется на 1 час
- [ ] После истечения часа блокировка снимается
- [ ] Таймер обновляется правильно

### API Совместимость

- [ ] `API.getStorage()` работает
- [ ] `API.setStorage()` сохраняет данные
- [ ] `API.showNotification()` показывает уведомления
- [ ] `API.onAlarm()` срабатывает в нужное время
- [ ] Все событие слушатели работают

### Производительность

- [ ] Нет утечек памяти (проверить в DevTools)
- [ ] Popup открывается быстро (< 1 сек)
- [ ] Трекинг времени не замедляет браузер
- [ ] CPU использование нормальное
- [ ] Батарея не разряжается быстрее

### Совместимость и регрессии

- [ ] Расширение работает в Chrome (проверить регрессию)
- [ ] Все функции работают одинаково в обоих браузерах
- [ ] Нет конфликтов с другими расширениями
- [ ] Работает с разными темами Firefox
- [ ] Совместимо с разными разрешениями экрана

### Локализация (Русский язык)

- [ ] Все русские тексты отображаются корректно
- [ ] Кириллица не имеет проблем с кодировкой
- [ ] Эмодзи отображаются правильно
- [ ] Сообщения читаются без ошибок

### Специфичные Firefox функции

- [ ] Синхронизация через Firefox Account работает
- [ ] Расширение работает в приватном окне
- [ ] Контейнеры (Multi-Account Containers) совместимы
- [ ] Работает с расширениями конфиденциальности
