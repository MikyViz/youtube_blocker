# Firefox Support для YouTube Blocker

## ✅ Реализовано

Расширение теперь полностью совместимо с **Firefox** благодаря новому слою совместимости API.

### Что изменилось

1. **Новый модуль API совместимости** (`modules/api-compatibility.js`)
   - Автоматически определяет браузер (Chrome или Firefox)
   - Предоставляет единый интерфейс для всех API вызовов
   - Firefox использует `browser` API вместо `chrome`

2. **Обновлены все модули**
   - Все вызовы `chrome.*` заменены на `API.*`
   - Полная совместимость с Firefox WebExtensions API
   - Сохранена полная обратная совместимость с Chrome

### Поддерживаемые функции

✅ Синхронизация хранилища (storage.sync)
✅ Уведомления системы
✅ Сигналы (alarms) для фоновых проверок
✅ Управление вкладками
✅ Сообщения между скриптами
✅ Runtime события

## 🔧 Как запустить в Firefox

### Для разработки

1. Откройте `about:debugging#/runtime/this-firefox` в Firefox
2. Нажмите "Load Temporary Add-on" ("Загрузить временное дополнение")
3. Выберите файл `manifest.json` в папке проекта
4. Расширение будет загружено в Firefox

### Для производства

1. Загрузите все файлы проекта на [Firefox Add-ons](https://addons.mozilla.org/)
2. Пройдите процесс проверки Mozilla
3. Расширение будет доступно в Firefox Add-ons

## 📋 Требования Firefox

- **Версия Firefox:** 88+ (для полной поддержки Manifest V3)
- **Permissions требуемые:**
  - `storage` - для синхронизации данных
  - `notifications` - для уведомлений
  - `alarms` - для фоновых проверок
  - `<all_urls>` - для доступа к YouTube

## 💡 Как работает совместимость

```javascript
// Автоматический выбор API
const browserAPI = typeof browser !== 'undefined' ? browser : chrome;

// Все функции используют выбранный API
API.getStorage(['key'])      // Работает в обоих браузерах
API.setStorage({key: value}) // Работает в обоих браузерах
API.showNotification(...)     // Работает в обоих браузерах
```

## 🐛 Известные проблемы

- Firefox может показывать немного другие уведомления (зависит от темы оформления ОС)
- Некоторые анимации CSS могут отличаться в зависимости от версии Firefox
